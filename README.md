# 人鱼之歌 - 海洋学校的毕业典礼

一个充满浪漫与奇幻的互动故事应用，讲述了在海洋学校毕业典礼这天发生的四个奇妙爱情故事。

## 🌊 项目简介

在深海的珊瑚学院，人鱼学生们度过了美好的学习时光。今天，是毕业典礼的日子，也是许多奇妙爱情故事开始的日子...

## ✨ 功能特点

- 🏫 **海洋学校场景** - 精美的首页展示珊瑚学院
- 🎓 **毕业典礼** - 沉浸式的毕业典礼场景
- 💕 **四个爱情故事** - 每个故事都有独特的主题和情节
  - 珊瑚与珍珠的约定
  - 潮汐下的秘密
  - 海星与贝壳
  - 深海的回音
- 🎨 **精美的UI设计** - 海洋主题的视觉效果和动画
- 📱 **响应式设计** - 适配各种设备尺寸

## 🚀 快速开始

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

应用将在 `http://localhost:5173` 启动

### 构建生产版本

```bash
npm run build
```

### 预览生产版本

```bash
npm run preview
```

## 🎯 使用说明

1. 打开应用后，首先看到海洋学校的首页
2. 点击"进入毕业典礼"按钮，进入毕业典礼场景
3. 在毕业典礼页面，可以看到四个爱情故事卡片
4. 点击任意故事卡片，开始阅读该故事
5. 在故事页面，可以通过导航按钮翻页阅读
6. 随时可以返回毕业典礼或首页
