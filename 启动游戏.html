🎮 五子棋游戏 - 启动说明

✅ 项目已构建完成！
生产版本已生成在 dist 文件夹中

方法1：使用本地服务器（推荐）

由于浏览器安全限制，需要启动一个本地服务器才能运行React应用。

选项A：使用Python（最简单）

如果已安装Python：

# Python 3 cd dist python -m http.server 8080 # 然后在浏览器打开： # http://localhost:8080/gomoku

选项B：使用Node.js

如果已安装Node.js：

# 安装 serve（如果还没有） npm install -g serve # 启动服务器 cd dist serve -s . -l 8080 # 然后在浏览器打开： # http://localhost:8080/gomoku

选项C：使用VS Code Live Server

如果使用VS Code：

  1. 安装 "Live Server" 扩展
  2. 右键点击 dist/index.html
  3. 选择 "Open with Live Server"
  4. 浏览器会自动打开，访问 /gomoku 路由

方法2：开发模式（推荐用于开发）

运行开发服务器，支持热重载：

npm install npm run dev # 然后在浏览器打开： # http://localhost:5173/gomoku
⚠️ 重要提示：
React应用不能直接双击HTML文件运行，必须通过HTTP服务器访问。 这是因为React使用了模块系统和路由，需要服务器环境。

📋 快速启动脚本

我已经创建了启动脚本，你可以：

  • Mac/Linux: 运行 ./start.sh
  • Windows: 双击 start.bat
